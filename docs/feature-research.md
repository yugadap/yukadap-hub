# 이유식 기록 — 필요 기능 리서치

조사일: 2026-11-26
방법: 웹 검색으로 공개된 자료(앱 스토어 상세 설명, 제품 소개 페이지)를 읽고 부모들이 이유식 기록에 필요로 하는 기능을 정리했습니다. 다른 앱의 코드, 화면 디자인, 이미지, 문구는 가져오지 않았습니다.

## 1. 참고한 공개 자료

| 앱 | 핵심 포지션 | 기록 방식 | 알레르기/반응 | 강점 | 약점 |
|---|---|---|---|---|---|
| 베이비타임 | 육아 통합 기록 | 원터치 기록(수유·이유식·수면 등) | 명시 없음 | 최소 터치, 통합 타임라인 | 이유식 전용 기능 얕음 |
| 맘마플래너 | 이유식 식단 | 식단표 + 반응 체크 | 알레르기 의심 재료 판별, 재료 궁합 | 재료 중심 사고 | 입력 단계 많음 |
| 스푼타임 | 이유식 로그 | 사진 업로드 → 일시·레시피·양 자동 기록 | 알레르기 재료 체크 | 입력 자동화 | 사진 의존 |
| 이유식 달력 | 달력 식단 | 달력 표시 | 재료별 이상반응 체크리스트 | 한눈에 보는 달력 | 통계 약함 |
| Solid Starts | 첫 100가지 음식 | 식사 로그 → 트래커 자동 저장 | 반응 기록, 의사 공유용 내보내기, 알레르겐 단계 도입 | 재료 DB·가이드 | 유료, 날짜 오기록 리뷰 |

## 2. 필요 기능 → 적용

| 필요 기능 | 적용 내용 (`index.html`) |
|---|---|
| 원터치 진입 | 하단 고정 `+ 기록하기` FAB, 시간·날짜·양 자동 채움(직전 양 기억) |
| 재료 중심 | 끼니 기록 시 재료 칩 입력 → 식재료 탭에 자동 집계 |
| 새 재료 3일 테스트 | 첫 시도일 기준 3일 연속 여부 진행바, 상태: 테스트 중 / 통과 / 이상반응 |
| 반응 체크 | 발진·두드러기·구토·설사 등 체크박스, 재료별 누적 표시 |
| 알레르기 주의 재료 | 주요 18종 시도 여부 그리드(미시도/통과/⚠) |
| 의사 공유 | CSV 내보내기(엑셀 호환 BOM) |
| 월령·단계 | 생일 → 개월/일수 + 초기·중기·후기·완료기, 이유식 D+N |

## 3. 차별점 / 의도적 제외

- 가입·서버 없음: localStorage 저장 + JSON 백업/복원 (Solid Starts의 날짜 오류 리뷰 → 날짜 직접 지정, 미래 날짜 차단)
- 무료·광고 없음, 기존 SAY & MORE 디자인 토큰 재사용
- 제외(v2 후보): 사진 기록, 식단 플래너/달력 뷰, 가족 공유(서버 필요), 영양 분석

## 4. 디자인에 쓴 스킬

- apple-design (Apple HIG): 라이트·다크를 기기 설정에 맞춤, 44pt 터치 영역, 대비 4.5:1 이상, 날짜별 묶음 목록, 하단 시트
- hallmark: 색·간격 토큰, 점검 스크립트(sloplint) 실패 0
- frontend-design, impeccable: 이유식 재료에서 가져온 색(쌀미음 바탕, 단호박 주황, 완두콩 초록, 노른자 노랑, 비트 빨강)
- web-design-guidelines, ui-ux-pro-max: 접근성, 입력 오류 위치, 되돌리기, 주소에 상태 저장
- react-best-practices: 파생 데이터 캐시, Map/Set 조회
